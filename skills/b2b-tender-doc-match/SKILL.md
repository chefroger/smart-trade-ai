# B2B 招标文件匹配归档

按招标清单把本地文件库里的图纸 / 技术文件匹配出来，重命名并归档。

## 输入

- 招标清单（结构化表格：序号、名称、数量，可选图号）
- 本地文件库文件夹
- 归档根目录
- 重命名规则（默认 `<序号>-<原文件名>`，需用户确认）

## 输出

- 归档目录：单文件平放，成套项进 `<序号>/`
- 报告：匹配数、未匹配数、未匹配清单、匹配率、回读验证

## 处理方式

> **语言**：脚本输出支持中英双语 —— 用户用英文对话时加 `--lang en`
> （或设 `TRADE_LANG=en`），默认中文。

```bash
# 只出计划（默认）
python scripts/match_archive.py --items items.json --library "<文件库>" --dest "<归档目录>"

# 确认后执行
python scripts/match_archive.py --items items.json --library "<文件库>" --dest "<归档目录>" --apply
```

## 匹配顺序

| 档 | 判据 | 说明 |
|---|---|---|
| 1 | 编号规范化后相等 **且** 名称相关 | 主力策略 |
| 2 | 名称相等（折叠空白、转小写） | 无编号时用 |
| 3 | 名称互含 | 最后兜底 |
| — | 皆无 | 输出候选，不归档 |

## 使用限制

- 只认文件名，不读文件内容。
- 不删除源文件（默认复制）。
- 不自动判定「哪个更像」——拿不准就留给用户看候选清单。
