# B2B 招标发现

在公开采购平台实时找标、筛标、评估。**不写标书**。

## 输入

- 品类 / 产品（可附 HS 编码）
- 目标国家或区域
- 预算范围、招标类型、截止时间窗口（可选）
- 搜索词语言（用户指定）

## 输出

- 概览表：编号 / 标题 / 采购方 / 预算 / 截止 / 匹配度 / 紧迫性 / 来源
- 逐条详情：13 个结构化字段
- 未能获取的信息清单
- 建议行动：优先跟进 / 关注备选 / 定期监控

## 处理方式

1. 先确认至少 3 项输入，不足先问再搜。
2. 公开平台搜索，每个平台至少 2 个查询角度；搜索词按用户语言各一套。
3. 逐条结构化提取，缺项写「未提供」，不猜。
4. 机会评估：匹配度 + 紧迫性 + 可行性。
5. 汇总报告，每条都带来源 URL 与发布日期。

## 使用限制

- 只在公开渠道搜索；需要登录或付费的平台只给链接并注明「需注册」。
- 不做供应商寻源、不做比价、不做投标文件撰写。
- 不保证覆盖所有平台；覆盖范围要在报告里如实说明。
