# B2B 招标大文件下载

把招标文件包完整下载并校验。只负责「拿到完整文件」。

## 输入

- 对象清单 `objects.json`（名称 / 下载地址 / 大小 / 校验值），由对象存储 API
  或平台接口导出；**用户当次提供**
- 目标目录
- 凭据（如需）：由用户当次提供，不写进任何文件

## 输出

- 完整文件（大小 + 校验值双对上）
- 失败清单与原因

## 处理方式

> **语言**：脚本输出支持中英双语 —— 用户用英文对话时加 `--lang en`
> （或设 `TRADE_LANG=en`），默认中文。

```bash
python scripts/tender_download.py --manifest objects.json --target-dir "<目标目录>"
```

| 阶段 | 做什么 | 失败时 |
|---|---|---|
| 诊断 | 查已有分片 / 目标是否完整 / 是否已有锁 | 有活锁 → 拒绝，报持有者 PID |
| 取清单 | 读 name/url/size/checksum | 缺字段的条目跳过，不猜 |
| 分块下载 | Range 分块 + 断点续传 + 重试 | 单块重试 3 次；不支持 Range 退回单流 |
| 完整性验证 | 大小 + 校验值 | 不符 → 删目标文件，判未完成 |
| 清理 | 删分片中间态、释放锁 | — |

## 使用限制

- 只支持 HTTP(S) 的 Range 下载；需要登录态的对象存储，凭据由用户当次提供。
- 不负责解压、不负责判断包内是否加密（那是 `b2b-tender-archive` 的事）。
- 不提供断点续传之外的加速手段（多线程数由 `--pieces` 控制，默认 4）。
