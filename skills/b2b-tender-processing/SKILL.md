# B2B 招标整理与询价单

把已抓下来的招标（主文件 + 附件）整理成标准项目文件夹，并生成 11 列询价单。

## 输入

- 邮件归档目录，或招标编号 + 主文件 + 附件
- 交付根目录（默认桌面；服务账户下必须显式给绝对路径）
- 用户指定的源语言（读扫描件时用）

## 输出

- 项目文件夹 `<日期>-<招标编号><核心品名>-<状态>/`
  - 主文件（原名）
  - `1_xxx`、`2_xxx` …（编号附件）
  - `<品名>.xlsx`（11 列询价单）
- 交付报告：数量、缺主文件与否、待人工核对项、与主文件不一致处

## 处理方式

> **语言**：脚本输出支持中英双语 —— 用户用英文对话时加 `--lang en`
> （或设 `TRADE_LANG=en`），默认中文。

```bash
python scripts/build_inquiry_sheet.py --spec items.json --root "<交付根目录>"
```

| 列 | 来源 | 缺省 |
|---|---|---|
| 序号 | 1..n | — |
| 物料号 | 主文件行项号 / 部件图号 | 空 |
| 名称（原文） | 主文件原文 | 空 |
| 名称（译文） | 按行业习惯翻译；装配体加「（单台 N × M 台）」 | 空 |
| 数量 | 源数字换算成数值；装配体 = 单台 × 台数 | 骨架「待确认」 |
| 图纸单重 | 图纸明细 / 标题栏 | 「按图纸」 |
| 总重 | 公式 = 数量 × 单重 | 单重非数值时留空 |
| 材质 | 图纸明细 / 标题栏 | 「按图纸」 |
| 单价 / 总价 / 交货期 | 内部填 | 留空 |

## 使用限制

- 不做翻译润色（译名按行业习惯给通行译法即可）。
- 不做比价、不做供应商寻源。
- 不修改源主文件与源附件。
- 扫描件图片理解依赖模型能力；模型不支持源语言时如实告知，不硬猜。
