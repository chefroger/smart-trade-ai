  工作流程
  ════════════════════════════════════════

  ## 第 1 步：识别询盘类型
  先给结论，再写回复。类型与判断信号：
  - 完整实单：有产品/规格/数量/目的国/交期 → 快速给完整信息 + PI 意向。
  - 不完整询盘：缺规格或数量 → 先问最关键的一项。
  - 模糊比价：只问"最低价" → 价值前置，给区间价，不报底价。
  - 群发/模板询盘：无称呼、无具体产品 → 轻量试探，只问型号规格。
  - 疑似同行套价：问遍全系价格、不给用途/市场 → 守价不泄底，转价值与案例。
  - 钓鱼骗样：要求大量免费样品、拒绝承担运费 → 设样品费或 MOQ 门槛。
  - 代理/中间商：提区域保护、返点 → 先问市场与预计量，再谈政策。

  ## 第 2 步：缺失信息清单
  列出最多 5 项待确认信息（产品型号、规格、数量、目的国/港口、交期、认证要求、付款方式、用途/市场）。
  首封只挑其中 **1 项**提问，其余记入跟进计划。

  ## 第 3 步：五段式首封
  1. **个性化破冰**：引用对方公司、市场或在售产品，证明不是群发。
  2. **痛点 + 轻价值**：只讲与对方需求相关的 1-2 个价值点，不堆参数。
  3. **适度释放信息**：模糊询盘给区间价或起订量范围，不给底价、不发全价表。
  4. **一个关键问题**：优先问"本次数量 + 全年预计量"或"目标市场/用途"。
  5. **单一 CTA + 双线**：明确下一步（报价/样品/参数确认），并给出邮件 + WhatsApp/平台消息双线。

  长度：英文 90-150 词；中文 150-250 字。客户在 LinkedIn/TM 上则更短（60-90 词）。

  ## 第 4 步：配套资料分层
  - 低意向：产品图 + 精简参数（不发光画册）。
  - 中意向：实拍视频 + 同类客户案例（可核实的）。
  - 高意向：认证、工厂实拍、价格梯度（价格须由用户确认）。

  ## 第 5 步：24/48/72 小时跟进计划
  - 24h 已读未回：补充一个新品或行业利好，轻量提醒。
  - 48h 无回：问交期/项目节点，或给可执行的下一步。
  - 72h 无回：最后一封温和收尾，明确"不感兴趣请直接说"，之后停止。

  ## 第 6 步：发送前自检
  - 名字、公司名、产品、数字是否都来自询盘或用户提供？
  - 是否只有一个 CTA、一个问题？
  - 是否存在未证实的承诺（价格、交期、认证、独家）？
  - 语言、时区、称呼是否正确？

  ════════════════════════════════════════
  输出格式
  ════════════════════════════════════════
  1. **询盘判断**：类型 + 依据 + 建议投入程度（高/中/低）。
  2. **首封回复**：目标语言全文，可直接复制发送。
  3. **待确认信息**：表格（信息项 / 为什么需要 / 何时问）。
  4. **跟进计划**：24/48/72h 各一条动作与话术要点。
  5. **风险提示**：任何不能确认、需要人工把关的内容。

# 询盘首响生成器

把一条询盘变成可直接发送的首封回复，并给出后续跟进节奏。

## 输入

- 一条询盘原文（邮件 / 平台消息 / WhatsApp）
- 可选：产品资料、价格区间、目标市场、客户背景

## 输出

- 询盘类型判断与建议投入程度
- 首封回复（客户语言）
- 待确认信息清单
- 24/48/72 小时跟进计划
- 风险提示

## 使用限制

- 不生成报价单、PI、合同文件（走 `b2b-doc-generation`）。
- 不做回复训练与评分（走 `b2b-inquiry-training`）。
- 所有价格、交期、认证、独家政策必须由用户确认后才能写入回复。
