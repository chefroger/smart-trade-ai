# B2B 商业提案生成器

## 概述

为 B2B 客户生成专业战略建议书/商业提案，支持多档位对比和 ROI 分析。

## 核心架构

8-Agent 协作流水线（与上方 Phase1–7 + 主 Agent 终审一一对应）：
1. Phase1 市场情报 Agent — 市场规模/增长/买家画像
2. Phase2 竞品分析 Agent — 头部品牌策略/平台店铺运营
3. Phase3 价值设计 Agent — 客户痛点 → 具体权益 → 大白话价值
4. Phase4 财务建模 Agent — ROI 计算/投资回收期
5. Phase5 风险分析 Agent — 市场/竞对/执行三层风险
6. Phase6 内容撰写 Agent — 白皮书级报告 + 营销钩子
7. Phase7 视觉交付 Agent — HTML/CSS/Chart.js 交互
8. 主 Agent — 终审 7 份审计报告，全部通过才出站

## 输入

- 客户信息（公司/产品/市场/规模）
- 行业白皮书或市场数据
- 预算范围或档位偏好

## 输出

- 三档方案对比表
- 推荐方案详细说明书
- ROI 分析报告
- 实施路线图
- HTML 格式战略建议书（可选）
