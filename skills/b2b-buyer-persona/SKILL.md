# B2B Buyer Persona & Role-Based Messaging

## 概述

分析 B2B 采购决策结构中的不同角色（采购经理、技术工程师、高层决策者），为每个角色定制价值主张、沟通策略和开发信，最大化转化率。

## 输入

- 产品信息（名称、规格、优势）
- 目标客户类型
- 目标市场/国家
- 客单价（可选）

## 输出

- 3 个决策角色的结构化分析
- 按角色的 FAB 价值主张
- 按角色的沟通策略
- 触达顺序路线图

## FAB 方法论

Feature（功能）→ Advantage（优势）→ Benefit（利益）

同一 Feature 对不同角色翻译为不同的 Benefit：
- 采购经理：成本节约、交期稳定、风险低
- 技术工程师：性能参数、认证合规、可集成性
- 高层决策者：ROI、市场份额、竞争力
