# Trade 功能介绍

Trade 是一款**本地运行**的 AI 外贸业务助手：一个聊天窗口 + 一套外贸业务工具（客户、订单、邮箱、文档、背调、定时任务）。数据保存在你自己的电脑上（SQLite + 本地文件），AI 由你自己的大模型 API Key 驱动。

> 模型：项目全部测试均在 **DeepSeek** 上完成，因此只推荐 DeepSeek（兼容其它 OpenAI 接口模型，但未验证）。

---

## 一、快速开始

1. 安装后运行 `trade` 或打开桌面版 **TradeWin**，浏览器打开 `http://127.0.0.1:9119/trade`。
2. 首次使用填写一个大模型 API Key（推荐 DeepSeek）。
3. 新手引导里创建公司档案（公司名、产品、目标市场等），AI 会据此写开发信、做分析。
4. **免费试用 30 天**（`TRADE_TRIAL_DAYS` 可调）。试用结束前 7 天会在侧栏提示，可随时输入激活码转正式版。

---

## 二、试用版（30 天）能用什么

试用版聚焦「聊天 + 获客」，已覆盖外贸日常最常用的问答与开发客户场景。

### 1. 今日简报（工作台）
- 每日 KPI：新询盘（暂显示「—」）、**逾期跟进客户数**、**待出货订单数**。
- 早安摘要：定时任务生成后显示当日简报全文。
- 右侧常驻栏：**待办清单**（当前时段条目红字高亮，30 秒轮询刷新）、**定时任务输出**。

### 2. 智能对话
- 通用外贸问答：产品、市场、单证、物流、报价思路等。
- 多轮上下文 + 会话记忆；重要对话可标记、评分。
- 支持拖拽/上传文件让 AI 阅读分析（随对话提问）。
- 助手回复支持 Markdown、表格、代码块；AI 可按约定输出**四格要点卡 / 邮件草稿块 / 下一步建议（NEXT）**。

### 3. 获客引流（五项）
| 栏目 | 做什么 |
|---|---|
| 客户开发 | 按产品/市场找客户方向、写开发信与跟进序列 |
| 网站诊断 | 分析客户官网：定位、产品线、可切入点 |
| 社媒营销 | Facebook/Instagram 等社媒内容与投放思路 |
| LinkedIn 营销 | 人设、内容日历、加人话术、私信跟进 |
| 海关数据 | 进出口记录解读、采购规律与竞品分析 |

- 内置 **40+ 个外贸技能**，按关键词自动匹配并注入专业规则（无需手动选技能）。
- 中 / 英文界面切换。

### 4. 基础设置
- 公司档案与 AI 人设（agent identity）编辑。
- 今日 token 用量统计、许可证状态、动效开关、新手引导重跑。

**试用版不包含**：客户管理、订单、邮箱、文档库、文档生成、客户背调、定时任务管理、对话记录页；也不能新增公司或导入/导出公司数据。

## 三、订阅版（激活许可证后）新增什么

激活后，侧栏「销售转化 / 工具 / 历史」三组栏目全部解锁。

### 1. 客户管理（CRM）
- **客户列表**：11 列（客户、分级、国家、买家类型、商机阶段、标签、订单数、订单总额、最近联系、下次跟进），支持搜索、分级/国家/买家类型/阶段筛选、只看星标、只看逾期、排序、分页。
- **客户详情卡片墙**：
  - 人物：主联系人 + 附加联系人（职能、职责、邮箱/电话/WhatsApp/WeChat）。
  - 订单、邮件、重要/最近对话、互动时间线（下单、出货、邮件、对话、今日应回复）。
  - 客户级**跟进备注**单独展示在主联系人卡片。
  - 商机阶段（询盘/报价/样品/订单，支持自动推导或手动锁定）。
- **客户画像（Asset Dossier）**：人物圈（家庭、其他供应商/竞品）、喜好/禁忌/重要日期、礼物往来（我方赠送/客户赠送/客户索要）；每条可确认/作废、控制「给 AI 用」，保留原句出处。
- **询盘**：新建/推进阶段，驱动客户阶段自动推导。
- **逾期跟进闭环**：逾期客户数在侧栏「客户管理」角标；客户列表一键筛逾期 → 行内「处理」→ 设置新的下次跟进日或「不再跟进」→ 写跟进事件到时间线 → 角标随逾期清零自动消失。
- **CSV 批量导入、公司数据导出/导入、多公司管理**。

### 2. 订单
- 客户下建订单：产品、数量、单价、金额、多币种（多币种不折算，分币种展示）。
- 物流字段：Incoterm、装运港、柜型、交期说明、出货日期。
- 状态进度：报价中 → 已下单 → 已出货 → 已完成（取消单单独呈现）。
- 状态变更写入**订单事件**，进入客户时间线。

### 3. 验厂计划（与客户绑定）
- 入口：客户详情页 →「验厂」。
- 计划表单：行程与来访人、日程、人员分工、访前清单、内部风险、对外说明；保存到本地数据库，可多次来访。
- **A4 打印**：公开页（给客户看）+ 内部页（红色「内部·勿外传」页头 + 水印，自动另起一页）。
- **手机长图**：一键生成 1080 宽 PNG（暗色页眉 + 分区正文），可直接下载发微信。

### 4. 邮箱
- 绑定 IMAP 邮箱（126/163/QQ/Gmail 等常见服务商）。
- **只读**拉取邮件，按客户聚合并与对话、时间线关联。
- 不会自动发送任何邮件；发送仍由你在自己的邮箱里完成。

### 5. 文档库与文档生成
- 文档库：按客户/主题建目录、上传产品资料、报价单、认证文件等。
- AI 可读取库内文档做**全量分析**（不做只读摘要替代）。
- **文档生成**：报价单、PI、合同、装箱单、商业提案，支持 **DOCX / XLSX / PPTX**；技术图纸分析（PDF）。

### 6. 客户背调（OSINT）
- 六层尽调：邮箱注册痕迹 → WHOIS → 企业/个人邮箱判定 → 制裁名单（OFAC/UN/EU）→ 技术栈 → LinkedIn 核验。
- `holehe` 默认启用：一次探测 120+ 平台的邮箱注册情况。
- 输出风险评分与建议；结果仅供决策参考，需人工复核。

### 7. 定时任务
- 基于 Hermes Gateway 的 cron 自动化（如 09:00 早安简报、邮件处理、LinkedIn 加人、下班总结）。
- 今日待办与任务产出显示在右侧常驻栏；任务可回看输出。

### 8. 对话记录
- 全量历史对话检索、按主题/客户过滤、评分与质量统计。

## 五、共同能力与边界

- **引擎**：基于 Hermes Agent；模型需自备 API Key（推荐 DeepSeek）。
- **数据位置**：`~/.trade/`（SQLite 数据库 + 公司/客户文件目录），本机保存，不经过 Trade 的中转服务器。
- **隐私**：发给模型的内容仅限你输入与必要上下文；不包含客户身份信息（除你主动提供）。云端模型服务商会收到请求内容。
- **邮件**：只读，不代发；不读取未绑定邮箱。
- **AI 产出**：报价、单证、背调结论均需人工复核后使用。
- **系统**：Python 3.14；Windows / macOS（桌面版 TradeWin 内置窗口）。
