| 可能 | 判断依据 | 应对方向 |

## 这一条我不能照做

## 三、保险这一行不能简单"加上去"（这是最容易算错的地方）

按 Incoterms 2020 的 CIF 规则，**保险金额是以 CIF 价本身为基数**计算的（最低为合同价的 110%），而 CIF 价里又包含保险费 —— 两个数互相引用，形成循环。[事实]（Incoterms 2020 CIF 条款 A5 保险义务；建议以 ICC 官方文本核对）

**解法是把保险从基数里解出来：**

```
保险费 I = CIF × 110% × 费率 r
CIF = FOB + 运费 + I
=>  CIF = (FOB + 运费) ÷ (1 − 1.1 × r)
```

约束：`1 − 1.1r > 0`（费率必须小于约 90.9%，实务上远低于此）。[推断]

**还有一种常见但不规范的口径**：直接按 FOB 价 ×110% 投保，此时 `CIF = FOB + 运费 + 1.1 × r × FOB`，算出来会**略低于**上面的正确口径。两种都能在合同里成立，但报价单上必须写清用的是哪种，否则客户比价时会对不上数。[推断]
