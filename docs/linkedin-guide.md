# LinkedIn 获客功能使用说明

> Trade 内置了完整的 LinkedIn 客户开发能力——从"卖给谁"到"怎么发第一条消息"，你直接提问，Trade 帮你完成分析和内容。
> **免费领英会员和高级会员（Sales Navigator）都能用**，区别在于可用功能不同，下面分开说明。

---

## 一、普通会员（免费版）能做什么

免费版可以做完整的客户开发流程，Trade 会帮你完成所有分析工作：

### 1. 主页打造（7 天计划）

告诉 Trade"帮我优化领英主页"，它会给你每天的任务：头像、Banner、Headline、About、Experience、推荐信、隐私检查——照着改就行。

### 2. 内容营销

- 生成帖子文案（产品展示 / 工厂现场 / 客户案例 / 行业观点）
- 写行业文章（长文，能被谷歌搜到）
- **Document 引流**：把产品目录做成可下载文档发帖，吸引精准客户留资

### 3. 客户开发六步流水线（Trade 帮你逐步分析）

1. **客户画像**：先搞清"我的产品该卖给谁"——进口商、经销商、品牌商、批发商还是终端？Trade 按你的产品输出 5 类最值得开发的目标客户
2. **搜索关键词**：把"产品词"变成"买家词"——不是搜 "Furniture"，而是搜 "Furniture Importer Germany" 这类组合（含 Importer / Distributor / Wholesaler / Brand 等买家身份词）
3. **客户分类**：把搜到的一批公司按 A/B/C 分级，帮你先把最值得开发的挑出来
4. **找对人**：别只会搜 "Buyer"——Trade 会分析该公司里"谁负责筛选供应商、谁做技术评估、谁最终决策"，并给出对应的英文职位搜索词
5. **找切入口**：发消息前先研究对方"最近在推什么产品、做哪些市场、有什么动态"
6. **写第一条消息**：生成 3 个版本，60-80 词，开头直接结合对方业务

### 4. 群组玩法（免费版专属优势）

领英群**只能在免费版加入**（高级版反而加不了）——先在免费版加行业群，这是一条重要的客户池渠道。

> **免费版的限制**：搜索有次数和条件限制（最多 5 组关键词）、没有 InMail 直邮、不能保存搜索条件、无法追踪邮件阅读。

## 二、高级会员（Sales Navigator）多出什么

如果你开通了高级会员，以上功能全部可用，另外多出这些**效率倍增器**：

### 1. 客户画像 + 保存搜索（一次设置、永久复用）

- 把常用的搜索条件（职务组合）存成"客户画像"，以后每次登录直接调用，不用重复输入
- 建议按市场分开存：欧美客户一套、东南亚一套（不同市场的决策人职位不一样）

### 2. 保存搜索 = "买家侦探"

保存一组搜索条件后，**符合条件的新客户会自动出现**——你保存的搜索每隔几天就告诉你"新增了 159 个潜在客户"，不用再手动重复搜。

### 3. 40 个搜索维度 + 名录批量上传

- 搜索条件比免费版细致得多（免费 5 组 → 高级 10 组关键词）
- 手上的展会名录、客户名单可以**批量上传**（每表最多 1000 家），系统自动匹配出里面的决策者

### 4. Account IQ（账户智能）

打开任意目标公司，直接看到：

- **谁是你的"关系人"**（你和这家公司有哪些共同人脉）
- 该公司最该找谁
- 公司情报：最近的投资计划、业务增长数据、招聘动态

### 5. 决策链地图

把目标公司里相关的人拖进一张图，标出：谁支持你、谁反对、谁说了算——**不用再一个个猜**。

### 6. 意向信号（最容易出单的功能）

- 哪家客户在扩招（研发部招人 = 可能要上新设备）
- 哪个客户公司的员工看过你的主页 / 点过你的广告（高意愿信号）

### 7. Smart Link（追踪你的资料发给了谁）

把产品资料做成追踪链接发出去，你能看到：**谁看了、看了多久、转给了谁**——资料被采购转给老板的那一刻，你就知道该跟进谁了。

### 8. InMail 直邮

每月 50 条（客户回复会返还额度），可以给没有加好友的人直接发消息。

> **高级版额外能看到的**：联系人公开的邮箱 / WhatsApp、职业轨迹（他之前在哪些公司、现在谁有决策权）。

## 三、怎么让 Trade 帮你做

直接在对话里说需求就行，例如：

**免费用户可以说：**

- "帮我分析一下，我们的产品适合卖给哪几类客户"（客户画像）
- "帮我生成 30 组 LinkedIn 搜索关键词，找德国的家具进口商"
- "这些公司是我搜到的，帮我按 A/B/C 分类"（把公司名单发给它）
- "帮我分析这家公司的采购决策人是谁，给我职位搜索词"
- "帮我写 3 个版本的第一条领英消息"（附上客户资料）

**高级会员可以说：**

- "帮我设计客户画像，我要按市场分开存"
- "我该保存哪些搜索条件？怎么用新增客户提醒？"
- "帮我分析这个人 / 这家公司"（附链接，Trade 帮你梳理决策链）
- "帮我做一份 Smart Link 资料包发给这个客户"
- "帮我规划这个月的 InMail 怎么发"

## 四、重要提醒（两类用户都要注意）

1. **不要买非正规渠道的"个人版"**——两千三千那种，100% 会被领英封号，钱白花
2. **不要共享账号**——检测到直接永久封号
3. **不要短时间大量加人**——一天 100 个以内，频繁操作会警告，累计 3 次以上永久封号
4. 高级会员有"官方学习窗口"（头像 → 设置里），**建议全部学完**——它会给你评分，评分影响领英推荐给你的客户质量
