# LinkedIn 获客功能使用说明

> Trade 内置了完整的 LinkedIn 客户开发能力——从"卖给谁"到"怎么发第一条消息"，你直接提问，Trade 帮你完成分析和内容。
> **免费领英和付费会员都能用**，区别在于可用功能不同，下面按会员等级分开说明。
>
> 本说明按 LinkedIn 官方帮助中心（2026-09 核实）编写；平台功能会持续更新，具体以你账户界面实际显示为准。

---

## 〇、先确认你的会员等级

LinkedIn 付费版本分多档，**不是"免费/高级"两级**。先确认自己属于哪一档，再看对应章节：

| 版本 | 说明 |
|------|------|
| **免费 Basic** | 不付费；搜索有"商业使用限制"（额度官方不公开，每月 1 日重置） |
| **Premium Business** | 个人付费版：搜索额度提升、InMail 15 条/月、谁看过我；**不含**销售开发功能 |
| **Sales Navigator** | 专业销售工具，分 Core / Advanced / Advanced Plus 三档，能力递增（见第三节） |

> 怎么查：打开 LinkedIn → 头像 → 查看当前订阅名称。不确定就直接问 Trade："我该用哪些 LinkedIn 功能"。
>
> **找不到某个功能？先排查版本**：同叫 Sales Navigator，LinkedIn 在不同地区 / 渠道提供的版本功能范围可能不同。按"① 套餐档位 → ② 渠道版本 → ③ 在账户中查找"的顺序排查——先怀疑版本，不要怀疑操作。

## 一、免费会员（Basic）能做什么

免费版可以完成完整的客户开发流程，Trade 帮你完成所有分析工作：

### 1. 主页打造（7 天计划）

告诉 Trade"帮我优化领英主页"，它会给你每天的任务：头像、Banner、Headline（≤220 字符）、About（≤2600 字符）、Experience、推荐信、隐私检查——照着改就行。

### 2. 内容营销

- 生成帖子文案（产品展示 / 工厂现场 / 客户案例 / 行业观点）
- 写行业文章（长文，能被谷歌搜到）
- **Document 发帖**：把产品目录做成文档发帖（支持 PDF/PPT/Word，≤100MB、≤300 页），吸引精准客户评论或私信——LinkedIn 没有自动留资表单，客户互动后由你人工跟进

### 3. 客户开发六步流水线（Trade 帮你逐步分析）

1. **客户画像**：先搞清"我的产品该卖给谁"——进口商、经销商、品牌商、批发商还是终端？Trade 按你的产品输出 5 类最值得开发的目标客户
2. **搜索关键词**：把"产品词"变成"买家词"——不是搜 "Furniture"，而是搜 "Furniture Importer Germany" 这类组合（含 Importer / Distributor / Wholesaler / Brand 等买家身份词）
3. **客户分类**：把搜到的一批公司按 A/B/C 分级，帮你先把最值得开发的挑出来
4. **找对人**：别只会搜 "Buyer"——Trade 会分析该公司里"谁负责筛选供应商、谁做技术评估、谁最终决策"，并给出对应的英文职位搜索词
5. **找切入口**：发消息前先研究对方"最近在推什么产品、做哪些市场、有什么动态"
6. **写第一条消息**：生成 3 个版本，60-80 词，开头直接结合对方业务

### 4. 连接邀请 + 留言

关注 → 对方发帖就评论 → 有明确开发理由再发连接邀请。**留言上限 200 字符**（官方限制），Trade 帮你把话说到点子上。免费会员每月只有少数几条带留言额度（以界面提示为准），优先用在关键客户。

### 5. 群组（Groups）开发客户

领英群是一个重要客户池，玩法分三步（第 1 步在免费版做）：

1. **用免费版加群**：搜索行业群，把**人数多的群**加入
2. 如果你有 Sales Navigator：用它的群维度搜索 → 复制群名（要一字不差）→ 按国家 / 行业 / 画像过滤
3. 在群成员中按**职务**筛人（例如选 CXO 层级）

> 逻辑："你的买家加了什么群，你就去加什么群；买家在什么人堆里，你就去什么人堆里。"
> 免费版不能按条件筛选群成员——筛选能力在付费版。

> **免费版的主要限制**：搜索有商业使用限制（额度官方不公开）、没有 InMail 直邮、不能保存搜索条件、无法追踪资料访问、不能筛选群成员。合理做法：用精准搜索词减少无效搜索、错开使用时段。

## 二、Premium Business（个人付费版）多出什么

- 搜索额度提升（但仍有上限）
- **InMail 15 条/月**（累计上限 45 条），可给没加好友的人直接发消息
- "谁看过我"等个人主页增强功能

> 注意：Premium Business **不含** Sales Navigator 的销售开发功能（保存搜索、画像、Account IQ 等）。如果你主要做客户开发，Sales Navigator 才是对应产品。

## 三、Sales Navigator 多出什么（分三档）

Sales Navigator 分 **Core / Advanced / Advanced Plus** 三档，能力递增。以下标注了每项功能的最低套餐要求：

### 1. 保存搜索（Saved Searches）— [全部 SN 档]

把搜索条件存起来（Lead / Account 各最多 50 条），**符合条件的新客户会通过每周邮件 + 主页提醒自动推送**，不用再手动重复搜。

### 2. 客户画像（Personas）— [全部 SN 档]

可组合 **职能 / 职位 / 职级 / 地区** 四类条件（不是只能存职务）；最多建 5 个。建议按市场分开建：不同市场的决策角色不同（如有的市场老板拍板、有的市场经理主导）。

> 注意：Persona 只用于"找人"搜索，不用于"找公司"搜索；改完画像后，之前保存的搜索不会自动更新。

### 3. 账户列表 + CSV 批量上传 — [建列表全档 / CSV 导入仅 Advanced 及以上]

把目标公司存进账户列表（Account Lists）。**CSV 批量导入**（展会名录、客户名单）需要 Advanced 及以上：每表最多 1000 家公司，必填公司名（用标准公司名，不要填网址）。导入的是公司，之后还是要通过公司页和搜索找到具体联系人。

### 4. Account IQ（账户洞察）— [全部 SN 档]

打开目标公司的账户页，能看到：公司的战略重点、业务挑战、财务信息、增长和招聘信号等。**注意：不是每家公司都有完整数据**，没有时用官网、新闻、招聘网站补充。

### 5. 找人：Relationship Explorer + Best Path In — [全部 SN 档]

在目标公司页推荐**最多 8 位**相关联系人（可按画像筛选）；Best Path In 帮你找"通过谁最容易接触到目标"。
**共同联系人打法**：如果系统提示你和目标公司有共同联系人，优先请对方帮你写**介绍信**——比自己冷发开发信有效得多。

### 6. 理关系：Relationship Maps — [建图全档 / 与同事共享需 Advanced 及以上]

把一家公司里的联系人整理成关系图，可标记角色（决策者 / 支持者 Champion / 评估者 / 采购 / 影响者）、关系强度和备注；每账户最多 10 张图、每张 30 人。移动端不支持查看。

### 7. 购买意向（Buyer Intent）— [仅 Advanced 及以上]

识别正在产生购买行为的公司：如公司主页互动、官网访问（需对方网站装了 LinkedIn 追踪代码）、广告互动等。信号分两类：**公开信号**（能看到具体的人）和**私有信号**（只显示公司和职位）。**它是优先级排序的参考，不等于对方已有采购意向**——判断要结合职位和公开信息。

### 8. Smart Links（资料追踪链接）— [SN 套餐内，以你账户实际显示为准]

把资料（产品册 / 公司简介 / 报价 PDF）打包成一条追踪链接。能看到：谁看了（登录 LinkedIn 的人显示姓名职位）、点击几次、停留多久、访问时间。**看不到链接被转发给了谁**。若你账户里找不到这个功能，说明你的套餐不含。

### 9. InMail 直邮 — [全部 SN 档]

每月 50 条（三档一致）；用不完可结转，**累计上限 150 条**；90 天内对方回复/接受/拒绝会返还额度；每月 1 日补充。不能额外购买。额度稀缺，发之前先做客户分析。

### 10. 提醒（Alerts）— [基础提醒全部 SN 档]

主页的提醒区汇总：账户增长 / 风险 / 更新、新决策者、职位变动、新潜客、员工动态等。大部分提醒需要先**保存**对应账户/线索才会推送；部分高级提醒（购买意向、Smart Link 查看）有套餐要求。

### 11. 优势描述上传（Products & Services）— [全部 SN 档]

在个人设置里上传你的"优势 / 服务能力"描述（约 5000 字符），可以按市场建多个版本（欧洲客户一版、大客户一版）。之后打开目标客户时，系统会结合你的描述与对方档案给出匹配提示——配合 Trade 分析"如何搞定这个人"。

### 12. 大客户开发五步法（把上面的功能串起来用）

> 适用：开发大客户。核心思维转变：不要"这家公司做什么行业→找采购→报价"，要"**这家公司怎么赚钱 → 战略重心 → 遇到什么挑战 → 我的方案如何解决它的战略级痛点**"。

1. **找种子**：从已成交的大客户或行业龙头出发，用「查看类似公司」找"双胞胎公司"（相同痛点 + 相同预算）
2. **看简报**：打开目标公司的 Account IQ——战略优先级 / 关键挑战 / 财务健康，作为切入话术依据
3. **定决策人**：把相关人（决策者 / 财务 / 技术）拉进 Relationship Maps，锁定关键决策者（不找采购）
4. **看信号**：员工增长 + 行为信号（互动 / 访问），定优先级
5. **找路径**：请共同联系人写介绍信，或按 Best Path In 找最强关系路径

> Trade 能帮你做的是分析和内容：类似公司分析、决策人梳理、开场话术、开发信——平台操作部分照着上面步骤在 LinkedIn 里执行。

## 四、怎么让 Trade 帮你做

直接在对话里说需求就行，例如：

**免费用户可以说：**

- "帮我分析一下，我们的产品适合卖给哪几类客户"（客户画像）
- "帮我生成 30 组 LinkedIn 搜索关键词，找德国的家具进口商"
- "这些公司是我搜到的，帮我按 A/B/C 分类"（把公司名单发给它）
- "帮我分析这家公司的采购决策人是谁，给我职位搜索词"
- "帮我写 3 个版本的第一条领英消息，控制在 200 字符内"（附上客户资料）

**Sales Navigator 用户可以说：**

- "帮我设计 Persona 画像，我要按市场分开建"
- "我该保存哪些搜索条件？"（Saved Searches）
- "帮我分析这家公司"（附公司页链接，Trade 帮你梳理该找谁、按什么顺序接触）
- "帮我做一份 Smart Link 资料包发给这个客户"
- "帮我规划这个月的 InMail 怎么发"
- "帮我制定这个大客户的开发策略"（Trade 按五步法输出：类似公司 / 决策人 / 信号 / 切入话术）

## 五、重要提醒（所有用户）

1. **不要买来源不明的低价账号**（共享账号等）——有封号风险，且不受官方保护
2. **不要共享账号**——检测到直接永久封号
3. **邀请要克制**——官方邀请限制数值不公开，超限后账号会被限制发邀请（通常约 1 周，期间不能发、撤回也不解除）；"一天加好友不超 100 个"是经验安全值，不是官方数字
4. **1 度人脉上限 30000 人**（官方规则）
5. **防骗**：任何声称拥有"领英数据 / 领英客户库 / 能接入领英的 CRM"的第三方产品**都不可信**——LinkedIn 不会向第三方提供会员数据，这类产品通常是骗局或违规手段，别花钱买
6. Sales Navigator 有官方上手内容，建议新用户走一遍
