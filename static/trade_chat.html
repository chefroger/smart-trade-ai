⬆️ 如何升级 Trade

通过 Hermes（AI 助手）来升级 Trade 是最简单的方式。Hermes 会自动执行所有更新命令，遇到报错会自行排查重试。

操作步骤

  1. 打开终端：
    macOS — 在 Launchpad 搜索「终端」
    Windows — 按 Win+R，输入 powershell，回车
  2. 输入 hermes 并回车，启动 Hermes
  3. 在 Hermes 对话框中输入以下内容并回车：
帮我更新trade，并重启trade，地址是https://github.com/chefroger/smart-trade-ai

等待执行完毕，看到「重启完成」提示后，刷新浏览器页面（Ctrl+Shift+R）即可。

如果 hermes 命令找不到，说明 Hermes Agent 未安装。请先参考 安装说明 安装 Hermes。
